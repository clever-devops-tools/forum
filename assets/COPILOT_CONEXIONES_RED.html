Requerimientos de Red para GitHub Copilot

Este documento detalla todas las conexiones de red necesarias para el funcionamiento de GitHub Copilot en entornos empresariales, incluyendo uso en IDEs (Visual Studio Code, JetBrains, etc.) y navegador. Puede ser entregado al administrador de red y al equipo de seguridad del cliente para gestionar las excepciones necesarias en firewalls y proxies.

3. Consideraciones Técnicas

  • Protocolo: Todas las conexiones utilizan HTTPS (puerto 443).
  • Inspección SSL/TLS: No romper la cadena de certificados de GitHub/Microsoft.
  • Proxy autenticado: Configurar el IDE para usar el proxy si es necesario.
  • Actualizaciones: Los endpoints pueden variar según la región o cambios de GitHub/Microsoft. Revisar periódicamente la documentación oficial.
