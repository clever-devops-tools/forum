# Assets - Recursos Visuales del Workshop

## header.png

Coloca aquí la imagen de encabezado (header.png) para el workshop. 

**Especificaciones recomendadas:**
- Formato: PNG
- Ancho: 1200px (mínimo)
- Alto: 300-400px
- Se mostrará al 100% del ancho del contenedor

**Sugerencias de contenido:**
- Logo del proyecto o empresa
- Título del workshop: "Fullstack App Forum Workshop - Búsqueda de Personas"
- Iconos de tecnologías: Angular, Spring Boot, Quarkus, PostgreSQL
- Colores corporativos

Puedes usar herramientas como:
- Figma (https://figma.com)
- Canva (https://canva.com)
- Adobe Express (https://express.adobe.com)
